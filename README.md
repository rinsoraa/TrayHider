# TrayHider 托盘图标管家

**只隐藏，不结束进程。** 一个适用于 Windows 11 的托盘图标与窗口管理工具。

TrayHider 可以把任务栏右下角（含溢出面板）里的托盘图标隐藏起来，也可以把普通程序的窗口"收进托盘"，
对应的程序仍然在后台正常运行，功能完全不受影响。隐藏状态会被持久化保存：软件重启、甚至目标程序重新
注册托盘图标之后，后台守护都会自动把它再次隐藏。

- 最新版本：**v1.2.0**
- 适用系统：Windows 11 x64
- 许可证：MIT

## 使用方法

### 1. 启动

运行 `TrayHider.exe`。程序会扫描当前正在运行的托盘图标并列出，同时在自己的托盘区域放置一个图标。

主界面分为「**托盘图标**」与「**窗口**」两个分区，用顶部两个按钮切换：

- **托盘图标**：左侧是图标列表，右侧是操作区，列表项显示程序名、进程信息与当前状态（显示中 / 已隐藏）。
- **窗口**：列出当前所有可隐藏的窗口，可勾选后批量隐藏或恢复。

### 2. 隐藏托盘图标

1. 在「托盘图标」分区勾选要隐藏的图标（支持多选）。
2. 点击「**隐藏所选**」。
3. 对应图标会立刻从托盘与溢出面板中消失，而程序仍在后台正常运行。

快捷操作：

- 「全部勾选」/「反选」/「取消勾选」：快速调整选择。
- 「**全部隐藏**」：一次隐藏列表中所有未隐藏的图标，会弹出确认对话框。
- **双击**列表项：直接切换该图标的隐藏状态。

### 3. 显示托盘图标

1. 勾选列表中状态为「已隐藏」的图标。
2. 点击「**显示所选**」，图标会重新回到托盘。
3. 点击「**全部显示**」可一次恢复所有被隐藏的图标。

> v1.2.0 起，恢复图标改为**让目标程序自己重新注册托盘图标**，因此恢复后的图标右键菜单、
> 双击行为都与程序原本的完全一致（旧版本会由本软件伪造注册，导致右键菜单失效）。
>
> 少数程序不处理系统的托盘重建消息（实测本机样本里约 5/12，多为以管理员或系统权限运行的组件，
> 例如部分 NVIDIA 容器进程、安全软件托盘、反作弊组件）。这类图标会退回"仅保证可见"的方式，
> 状态栏与列表状态会明确标注"右键菜单可能失效"，重启该程序即可彻底恢复。

### 4. 把窗口隐藏到托盘

1. 切到「**窗口**」分区，列表会列出当前所有可隐藏的窗口（桌面、任务栏与本软件自身不会出现）。
2. 勾选目标窗口，点击「**隐藏所选**」；或直接双击列表项。
3. 窗口从屏幕消失，但程序仍在运行；托盘区会出现一个**同名图标**。
   - **单击 / 双击**该托盘图标：恢复窗口。
   - **右键**该图标：显示窗口 / 关闭窗口 / 显示全部窗口。
4. 点击「**全部恢复**」可一次把所有隐藏的窗口召回。

隐藏时会记录窗口的位置与显示状态（含最大化），恢复后窗口回到原来的位置和大小。

也可以在任意程序窗口处于前台时直接按 `Ctrl + Win + H`：把当前窗口收进托盘，连按两下则撤销这次隐藏。

可选联动：在设置里打开「**隐藏窗口时同时隐藏该程序的托盘图标**」后，隐藏窗口时该程序原本的托盘图标
也会一起消失，恢复窗口时自动回来，托盘区不会留下重复入口。

### 5. 开机自启动

在设置页打开「**开机自动启动**」。TrayHider 会写入当前用户的登录启动项，
以最小化方式启动，并在启动后自动恢复上次的隐藏状态。

### 6. 关闭窗口行为

设置页的「**关闭窗口时最小化到托盘**」：

- 开启（默认）：点击关闭按钮后程序继续在托盘后台运行，隐藏守护不中断。
- 关闭：点击关闭按钮即真正退出程序（被隐藏的窗口会被恢复）。

### 7. 隐藏本软件自身的托盘图标

在设置页打开「**隐藏本软件的托盘图标**」。隐藏后程序仍在后台运行，
可以随时用全局快捷键唤出主窗口。

### 8. 托盘右键菜单

右键点击 TrayHider 的托盘图标：

- 打开主窗口
- 隐藏全部托盘图标 / 显示全部托盘图标
- 隐藏全部窗口 / 显示全部窗口
- 退出

双击托盘图标同样可以唤出主窗口。

### 9. 设置页一览

| 分组 | 项目 |
| --- | --- |
| 启动与后台 | 开机自动启动、隐藏本软件的托盘图标、关闭窗口时最小化到托盘 |
| 窗口隐藏 | 隐藏窗口时同时隐藏该程序的托盘图标、退出本软件时恢复被隐藏的窗口 |
| 全局快捷键 | 5 个动作各自的组合键，逐条「修改」并即时生效 |
| 其他 | 恢复所有被隐藏的图标、配置文件位置（打开目录）、退出程序 |

## 全局快捷键

| 动作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 唤出主窗口 | `Ctrl + Win + T` | 无论主窗口是否可见、本软件图标是否隐藏都可用 |
| 隐藏 / 恢复当前窗口 | `Ctrl + Win + H` | 把前台窗口收进托盘；连按两下撤销这次隐藏；焦点在桌面 / 任务栏时恢复最近隐藏的窗口 |
| 隐藏全部窗口 | `Ctrl + Win + W` | 一次把所有可隐藏窗口收进托盘 |
| 显示全部窗口 | `Ctrl + Win + U` | 一次把所有被收进托盘的窗口恢复 |
| 全部隐藏 / 恢复托盘图标 | `Ctrl + Win + I` | 托盘里还有图标就全部隐藏，全部已隐藏则全部恢复 |

修改方法：

1. 打开主窗口，点击右上角「设置」。
2. 在「全局快捷键」区域找到对应动作，点击「**修改**」。
3. 按下新的组合键（例如 `Ctrl + Alt + H`）。

要求：至少包含一个修饰键（Ctrl / Alt / Shift / Win），且不能与其他程序冲突；
若注册失败，程序会自动回退到原快捷键并给出提示。个别快捷键被占用不影响其它动作。

## 工作原理

### 托盘图标

Windows 11 的任务栏托盘已经不再是传统的 `ToolbarWindow32` 按钮列表，
网上常见的 `TB_GETBUTTON` / `TB_DELETEBUTTON` 方案在新系统上已经失效。

TrayHider 走的是 Shell 托盘图标接口：

- 通过托盘注册信息定位目标项，按 UID / GUID 双标识匹配；
- **隐藏**：用 `Shell_NotifyIcon(NIM_DELETE)` 让 Shell 立即移除该图标，
  图标随即从托盘与溢出面板消失；
- **显示**：向目标程序的窗口投递系统消息 `TaskbarCreated`（注册消息），
  让**程序自己**用它的 `hWnd` / `uID` / `uCallbackMessage` 重新 `NIM_ADD`，
  再用无副作用的 `NIM_MODIFY` 探测确认回归；
- **降级**：极少数程序不响应托盘重建，这时才由本软件重建图标，只保证"看得见"，
  并在状态栏提示右键菜单可能失效（重启该程序即可恢复）；
- 后台守护周期性检查已隐藏项，目标程序重新注册图标时再次隐藏。

为什么恢复不能由本软件直接 `NIM_ADD`：`NOTIFYICONDATA` 是注册方的契约，
Shell 会把图标的鼠标消息投给注册时给出的窗口与回调消息号。本软件无法伪造出目标程序自己的回调，
于是"图标看得见但右键菜单点不动"（v1.1.0 的缺陷，v1.2.0 已修复）。
`TaskbarCreated` 恰好是 explorer 重启后 Shell 广播的那条消息——点对点投递它，
等于"只让这一个程序重建一次托盘图标"，效果与用户手动重启资源管理器相同，但代价小得多。

整个过程**不结束目标进程**，也不修改目标程序的任何文件。

### 窗口隐藏

- 枚举当前所有可隐藏的顶层窗口（排除不可见、无标题、工具窗口、`ApplicationFrameWindow` 之外的
  DWM 隐形窗口，以及桌面 / 任务栏 / Shell 窗口）；
- **隐藏**用 `ShowWindowAsync(SW_HIDE)`（异步投递，目标程序卡死也不会拖住本软件），
  隐藏前记录 `WINDOWPLACEMENT`；
- **恢复**用 `SetWindowPlacement` + `SW_SHOW` + `SetForegroundWindow`，窗口回到原来的位置与状态；
- 每个被隐藏的窗口会创建一个独立的托盘图标，图标取自窗口自身图标（拿不到就用程序图标），
  恢复 / 退出时一律销毁，不留悬挂图标；
- 「关闭窗口」是先恢复窗口再投递 `WM_CLOSE`，因此程序的"是否保存"对话框用户能看到，绝不强杀进程。

## 常见问题

**Q：快捷键没有反应？**

可能被其他软件占用。先用托盘图标打开主窗口，在设置中更换一组快捷键。
设置页会逐个动作显示注册结果，某个动作注册失败不影响其它动作。

**Q：恢复图标后右键菜单失效？**

v1.2.0 已修复该问题（改为让目标程序自己重新注册图标）。
若某个程序不响应系统托盘重建，状态栏会提示"右键菜单可能失效"，重启该程序即可恢复。

**Q：图标回来了，但右键菜单还是点不动？**

说明该程序没有响应系统的托盘重建消息（通常是提权运行的程序）。两种办法：

1. 重启那个程序——它启动时会用自己正确的注册信息重新添加图标，菜单立即恢复；
2. 重启资源管理器（任务管理器 → 找到「Windows 资源管理器」→ 重新启动），效果与系统重启托盘一致。

也可以在命令行里手动对某个程序触发托盘重建（仓库里的诊断脚本，只投递这一条系统消息，不做其它改动）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\post-taskbarcreated.ps1 -ProcessName 进程名 -Rounds 3
```

**Q：提示「无法定位图标」？**

部分程序重启后托盘窗口类名会变化，已加入兜底定位逻辑。
如果目标程序已经退出，需要先重新启动该程序，再执行恢复。

**Q：显示后图标没有回来？**

请确认目标程序仍在运行。程序退出后其托盘图标会随之消失，重新运行该程序即可看到图标。

**Q：窗口隐藏后程序还在运行吗？**

在运行。窗口只是被隐藏（`SW_HIDE`），进程、快捷键、后台任务、下载等都照常工作。
用托盘图标或快捷键恢复即可。

**Q：为什么有的窗口隐藏不了（例如以管理员身份运行的程序）？**

本软件默认以普通权限运行，Windows 的 UIPI 会拦截对高权限窗口的显示/隐藏请求。
表现为"点了隐藏但窗口还在"，此时程序会自动回退状态并提示。
需要管理这类窗口时，请以管理员身份运行 TrayHider。

**Q：直接退出 TrayHider，被隐藏的窗口会不会留在隐藏状态？**

不会。默认开启「退出本软件时恢复被隐藏的窗口」，正常退出（含托盘菜单退出）时所有窗口都会恢复。
只有在本软件被任务管理器强制结束的情况下才可能残留，重新打开任务栏托盘里的程序窗口即可
（窗口所属程序并未退出，可用任务栏预览或 Alt+Tab 找回）。

**Q：新版启动不了 / 双击没反应？**

TrayHider 使用单实例机制。如果旧版本仍在后台运行，请先在任务管理器中结束 `TrayHider` 进程，再启动新版本。

**Q：隐藏图标会影响程序功能吗？**

不会。隐藏只作用于托盘图标本身，进程、通知、热键等功能都不受影响。

**Q：内存占用高吗？**

v1.2.0 做了针对性优化：托盘扫描改为按需查询相关进程（不再每次遍历全系统进程并读取模块路径），
图标提取带弱引用缓存、按托盘尺寸（32px）解码，备份用的图标快照也规范化为 32×32 PNG，
配置文件写入做了短去抖。主窗口收起后切换到低频守护，CPU 与内存占用都更低。

**Q：怎么彻底恢复？**

点击「全部显示」，或在设置页使用「全部恢复」清空隐藏记录；窗口分区点击「全部恢复」召回所有窗口。

## 构建与发布

需要 .NET 8 SDK（含 Windows Desktop 组件）。

```bash
# 构建
dotnet build -c Release

# 发布 Portable（自包含）
dotnet publish -c Release -r win-x64 -p:PublishProfile=portable-win-x64

# 发布 Lite（依赖已安装的 .NET 8 Desktop Runtime）
dotnet publish -c Release -r win-x64 -p:PublishProfile=lite-win-x64
```

输出目录：

```text
bin/Release/net8.0-windows/win-x64/publish/portable/
bin/Release/net8.0-windows/win-x64/publish/lite/
```

### 发版前必须跑一次启动冒烟

**编译 0 warning 0 error 并不等于程序能启动。** WPF 的数据绑定错误要到窗口显示之后
（甚至是显示后几秒、绑定引擎的排版回调里）才会抛异常，表现为进程无提示退出（退出码 0xE0434352）。
v1.2.0 开发期间就踩过一次（`<Run Text="{Binding 只读属性}"/>` —— Run.Text 默认 TwoWay 绑定）。

```powershell
# 启动 20 秒，断言进程存活且主窗口句柄非 0，失败自动打印最近的 .NET 未处理异常
powershell -ExecutionPolicy Bypass -File scripts\smoke-test.ps1
# 也可以直接验证发布产物
powershell -ExecutionPolicy Bypass -File scripts\smoke-test.ps1 -ExePath bin\Release\net8.0-windows\win-x64\publish\portable\TrayHider.exe
```

## 更新日志

### v1.2.0

**新增**

- 新增「窗口」分区：把普通窗口隐藏到系统托盘，进程照常运行
  - 窗口列表（增量刷新、自动过滤桌面/任务栏/工具窗口）
  - 每个隐藏窗口一个独立托盘图标：单击恢复、右键菜单（显示 / 关闭 / 全部显示）
  - 保存并还原窗口位置与最大化状态
  - 可选联动：隐藏窗口时一并隐藏该程序的托盘图标
  - 退出本软件时自动恢复所有被隐藏的窗口
- 全局快捷键从 1 组扩展为 5 组，均可在设置中逐个修改：
  - 唤出主窗口、隐藏/恢复当前窗口、隐藏全部窗口、显示全部窗口、全部隐藏/恢复托盘图标
- 托盘右键菜单新增「隐藏全部窗口 / 显示全部窗口」

**修复**

- 修复「全部隐藏后再全部显示，图标右键菜单失效，只能重启资源管理器」的问题：
  恢复改为向目标程序投递 `TaskbarCreated` 让它自己重新注册图标，
  恢复后的右键菜单 / 双击与程序原生行为一致；对不响应的程序给出降级提示
- 修复托盘图标探测会改动目标程序 tooltip 的副作用（改用无副作用探测）
- 修复托盘列表单击延时定时器可能累积泄漏的问题
- 修复窗口在极端情况下可能被留在隐藏状态的问题（退出流程幂等）

**优化**

- 托盘扫描不再遍历全系统进程并读取模块路径，改为按需查询 + 短 TTL 缓存
- 图标提取加入弱引用缓存，按托盘尺寸（32px）解码
- 图标快照规范化为 32×32 PNG，配置文件与内存占用同步下降
- 配置写入增加短去抖，批量操作不再重复落盘
- 设置页按分组重排，快捷键逐条显示与修改
