# TrayHider 托盘图标管家

**只隐藏图标，不结束进程。** 一个适用于 Windows 11 的托盘图标管理工具。

TrayHider 可以把任务栏右下角（含溢出面板）里的托盘图标隐藏起来，而对应的程序仍然在后台正常运行，
功能完全不受影响。隐藏状态会被持久化保存：软件重启、甚至目标程序重新注册托盘图标之后，
后台守护都会自动把它再次隐藏。

- 最新版本：**v1.1.0**
- 适用系统：Windows 11 x64
- 许可证：MIT

## 使用方法

### 1. 启动

运行 `TrayHider.exe`。程序会扫描当前正在运行的托盘图标并列出，同时在自己的托盘区域放置一个图标。

主界面分为两栏：左侧是图标列表，右侧是操作区。列表项会显示程序名、进程信息与当前状态（显示中 / 已隐藏）。

### 2. 隐藏图标

1. 在列表里勾选要隐藏的图标（支持多选）。
2. 点击「**隐藏所选**」。
3. 对应图标会立刻从托盘与溢出面板中消失，而程序仍在后台正常运行。

快捷操作：

- 「全部勾选」/「反选」/「取消勾选」：快速调整选择。
- 「**全部隐藏**」：一次隐藏列表中所有未隐藏的图标，会弹出确认对话框。
- **双击**列表项：直接切换该图标的隐藏状态。

### 3. 显示图标

1. 勾选列表中状态为「已隐藏」的图标。
2. 点击「**显示所选**」，图标会重新回到托盘。
3. 点击「**全部显示**」可一次恢复所有被隐藏的图标。

### 4. 全局快捷键

默认快捷键：

```text
Ctrl + Win + T
```

无论主窗口是否可见、TrayHider 自身图标是否隐藏，都可以用它唤出主窗口。

修改方法：

1. 打开主窗口，点击右上角「设置」。
2. 在「唤出主窗口的快捷键」区域点击「**修改快捷键**」。
3. 按下新的组合键（例如 `Ctrl + Alt + H`）。

要求：至少包含一个修饰键（Ctrl / Alt / Shift / Win），且不能与其他程序冲突；
若注册失败，程序会自动回退到原快捷键并给出提示。

### 5. 开机自启动

在设置页打开「**开机自动启动**」。TrayHider 会写入当前用户的登录启动项，
以最小化方式启动，并在启动后自动恢复上次的隐藏状态。

### 6. 关闭窗口行为

设置页的「**关闭窗口时最小化到托盘**」：

- 开启（默认）：点击关闭按钮后程序继续在托盘后台运行，隐藏守护不中断。
- 关闭：点击关闭按钮即真正退出程序。

### 7. 隐藏本软件自身的托盘图标

在设置页打开「**隐藏本软件的托盘图标**」。隐藏后程序仍在后台运行，
可以随时用全局快捷键唤出主窗口。

### 8. 托盘右键菜单

右键点击 TrayHider 的托盘图标：

- 打开主窗口
- 显示全部图标
- 退出

双击托盘图标同样可以唤出主窗口。

### 9. 设置页一览

| 分组 | 项目 |
| --- | --- |
| 启动与后台 | 开机自动启动、隐藏本软件的托盘图标、关闭窗口时最小化到托盘 |
| 快捷键 | 唤出主窗口的快捷键（当前快捷键 / 修改快捷键） |
| 其他 | 恢复所有被隐藏的图标、配置文件位置（打开目录）、退出程序 |

## 配置文件

配置保存在：

```text
%APPDATA%\TrayHider\config.json
```

内容包括：

- 被隐藏图标的完整恢复信息（子键名、路径、UID / GUID 等）
- 全局快捷键
- 开机自启动设置
- 主窗口刷新间隔与后台守护间隔
- 关闭窗口行为

配置格式向后兼容：旧版本生成的配置文件可以被 v1.1.0 直接读取，隐藏记录不会丢失。

## 工作原理

Windows 11 的任务栏托盘已经不再是传统的 `ToolbarWindow32` 按钮列表，
网上常见的 `TB_GETBUTTON` / `TB_DELETEBUTTON` 方案在新系统上已经失效。

TrayHider 走的是 Shell 托盘图标接口：

- 通过托盘注册信息定位目标项，按 UID / GUID 双标识匹配；
- 隐藏时备份并移除对应的托盘注册子键，图标随即从托盘与溢出面板消失；
- 显示时按备份信息重建注册项，图标回到托盘；
- 后台守护周期性检查已隐藏项，目标程序重新注册图标时再次隐藏。

整个过程**不结束目标进程**，也不修改目标程序的任何文件。

## 常见问题

**Q：快捷键没有反应？**

可能被其他软件占用。先用托盘图标打开主窗口，在设置中更换一组快捷键。

**Q：提示「无法定位图标」？**

部分程序重启后托盘窗口类名会变化，v1.1.0 已加入兜底定位逻辑。
如果目标程序已经退出，需要先重新启动该程序，再执行恢复。

**Q：显示后图标没有回来？**

请确认目标程序仍在运行。程序退出后其托盘图标会随之消失，重新运行该程序即可看到图标。

**Q：新版启动不了 / 双击没反应？**

TrayHider 使用单实例机制。如果旧版本仍在后台运行，请先在任务管理器中结束 `TrayHider` 进程，再启动新版本。

**Q：隐藏图标会影响程序功能吗？**

不会。隐藏只作用于托盘图标本身，进程、通知、热键等功能都不受影响。

**Q：怎么彻底恢复？**

点击「全部显示」，或在设置页使用「全部恢复」清空隐藏记录。

## 构建与发布

需要 .NET 8 SDK（含 Windows Desktop 组件）。

```bash
# 构建
dotnet build -c Release

# 发布 Portable（自包含）
dotnet publish -c Release -r win-x64 -p:PublishProfile=portable-win-x64

# 发布 Lite（依赖已安装的 .NET 8 Desktop Runtime）
dotnet publish -c Release -r win-x64 -p:PublishProfile=lite-win-x64
```

输出目录：

```text
bin/Release/net8.0-windows/win-x64/publish/portable/
bin/Release/net8.0-windows/win-x64/publish/lite/
```
